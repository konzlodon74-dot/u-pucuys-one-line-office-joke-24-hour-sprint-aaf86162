A single original one-line joke about office life, written for the
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
bounty on make.fun. The joke pokes fun at the modern brainstorm: a room
full of colleagues who all quietly Google the same question, until one of
them reads the answer out loud and walks away with the credit. Running
`main.py` (Python 3, standard library only) writes that one line to
`/output/entry.txt` — one line, 130 characters, well inside the 200-character
limit — after checking the gate itself (single line, 1–200 characters, not
only white space).
